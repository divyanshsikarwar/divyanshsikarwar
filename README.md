### JEVision · Side project

A Qwen3.5-based system for structured decisions over text and images. The text route uses a trained LoRA adapter and pointer head; image-bearing requests route to a separate visual LoRA sidecar and pointer head. It returns typed **Choice**, **Noul**, and **Score** outputs through a JEV-style interface.

[Hugging Face model card](https://huggingface.co/divyanshx11/JEVision) · [GitHub repository](https://github.com/divyanshsikarwar/JEVision)
